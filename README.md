# SpaceMouse-Config-Files
3D Connexion Spacemouse Config files for my games.  
  
Files should be placed in C:\Users\username\AppData\Roaming\3Dconnexion\3DxWare\Cfg

## Tiny Glade
Remap zoom to keypad 8 and 2  
Remap rotate to keypad 7 and 9  

## Town to city
Looks like game does not support AZERTY config with QWERTY settings in the game.  
The config in the file works with AZERTY keyboard configuration.  
You might need to remap keys to work with QWERTY keyboard.
